HTML5 核心知识

持续更新 HTML

语义化标签

HTML5 引入了丰富的语义化标签，让页面结构更清晰：

<header> — 页面头部区域
<nav>   — 导航链接容器
<main>  — 主要内容区（每个页面仅一个）
<article> — 独立的内容块
<section> — 内容分组
<aside>  — 侧边栏/辅助内容
<footer> — 页脚区域
最佳实践：优先使用语义化标签而非 div，这对 SEO 和无障碍访问都有帮助。使用语义化标签可以让屏幕阅读器更好地理解页面结构。

Flexbox 布局模式

.container {
    display: flex;
    justify-content: space-between;  /* 主轴对齐 */
    align-items: center;             /* 交叉轴对齐 */
    gap: 16px;                       /* 元素间距 */
    flex-wrap: wrap;                 /* 允许换行 */
}

.item { flex: 1; }  /* 等分空间 */

Grid 布局

.grid-container {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
    gap: 20px;
}
注意：Flexbox 是一维布局（行或列），Grid 是二维布局（行和列同时控制）。简单的一维排列用 Flexbox，复杂的二维布局用 Grid。

DOM 操作最佳实践

// 使用事件委托（性能优化）
document.querySelector('.list').addEventListener('click', (e) => {
    if (e.target.classList.contains('item')) {
        // 处理点击事件
    }
});

// 使用 IntersectionObserver 实现懒加载
const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
        if (entry.isIntersecting) {
            entry.target.src = entry.target.dataset.src;
            observer.unobserve(entry.target);
        }
    });
});
document.querySelectorAll('img[data-src]').forEach(img => observer.observe(img));
性能提示：频繁操作 DOM 时，先使用 DocumentFragment 或字符串拼接批量操作，最后一次性插入 DOM，避免多次重排重绘。

前端性能优化

性能

加载性能优化

  • 资源压缩：使用 Gzip/Brotli 压缩文本资源，可减少 60-80% 体积
  • 图片优化：使用 WebP 格式，配合 lazy loading 延迟加载
  • CSS/JS 压缩：移除空格注释，缩短变量名
  • 关键 CSS 内联：将首屏关键样式内联到 HTML 中
  • 预加载关键资源：使用 <link rel="preload">

渲染性能优化

  • 减少重排重绘：批量修改 DOM，使用 CSS transform 替代 top/left
  • 虚拟滚动：长列表只渲染可视区域内的元素
  • 防抖节流：高频事件（scroll/resize）使用 debounce/throttle
  • will-change：提前告知浏览器元素将发生变化
// 防抖函数
function debounce(fn, delay = 300) {
    let timer;
    return (...args) => {
        clearTimeout(timer);
        timer = setTimeout(() => fn(...args), delay);
    };
}

// 节流函数
function throttle(fn, limit = 200) {
    let inThrottle;
    return (...args) => {
        if (!inThrottle) {
            fn(...args);
            inThrottle = true;
            setTimeout(() => inThrottle = false, limit);
        }
    };
}

代码规范

  • 使用一致的命名规范：驼峰式（camelCase）用于变量/函数，帕斯卡式（PascalCase）用于类/组件
  • 保持函数单一职责，一个函数只做一件事
  • 有意义的变量名优于简写：userList 比 arr 更好
  • 添加必要的注释，解释"为什么"而不是"做什么"

可访问性（A11y）

  • 图片始终提供 alt 属性
  • 表单元素关联 label
  • 确保足够的颜色对比度（WCAG AA 标准：4.5:1）
  • 键盘可访问：所有交互功能都应可通过键盘操作
  • 使用语义化 HTML 标签

安全注意事项

XSS 防护：永远不要直接将用户输入插入 DOM，使用 textContent 而非 innerHTML 处理不可信数据。

CSRF 防护：表单提交使用 CSRF Token 验证请求来源。
